# HCDS Lab · JEIU

**High-Performance Computing Lab for Digital Twins and Simulation**

We explore GPU-accelerated geometry processing and ray tracing
for 3D reconstruction, simulation, and Physical AI.

## Research

- GPU computing and hardware-accelerated ray tracing
- 3D geometry processing and reconstruction
- Digital twins, simulation, and Real2Sim
